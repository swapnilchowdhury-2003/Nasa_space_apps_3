## 💡 Proposed Solution & Overview
**AstroPulse / CrewCheck** is an offline-first astronaut health decision-support web application designed to bridge the gap between daily self-assessments and clinical baseline comparisons during deep-space or resource-constrained missions. 

### Key System Architecture & Features:
* **Personalized Baseline Engine:** Compares daily astronaut vitals directly against individual 14-day rolling personal baselines.
* **24-Hour Data-Quality Guard:** Prevents erroneous or incomplete logging spikes from triggering false alarms.
* **4-Tier Alert System:** Categorizes physiological shifts from nominal status to critical warning levels.
* **Interactive Health-Learning Modules:** Built-in guidance and support protocols tailored for autonomous spaceflight operations.
